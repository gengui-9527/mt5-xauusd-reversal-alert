# XAUUSD M5 PushPlus 手机提醒 EA 设计

## 目标

新增一个 MetaTrader 5 智能交易程序（EA），固定监控黄金品种的 M5 盘中行情。市场多空方向连续确认 10 秒后，同时发出 MT5 声音、弹窗和 PushPlus App 有声提醒。

EA 只负责监控与提醒，不执行开仓、平仓、改单或任何其他交易操作。

## 选择 EA 的原因

MT5 的 `WebRequest()` 只能由 EA 和脚本调用，不能由自定义指标调用。现有指标继续保留，新增 EA 复用相同信号与防抖规则，同时增加 PushPlus 网络请求能力。

交付物采用独立 EA，不要求现有指标配合运行。

## 信号和状态行为

EA 可加载在任意图表，但始终读取目标黄金品种的 `PERIOD_M5` 当前未收盘K线。

默认三因子投票：

1. EMA 9 高于 EMA 21 时投多票，低于时投空票。
2. Supertrend 使用 ATR 10、倍数 3.0；当前价高于趋势线时投多票，低于时投空票。
3. RSI 14 高于 50 时投多票，低于时投空票。

至少两个因子同向时形成有效候选方向。任一比较正好相等时，对应因子不投票。

状态机规则：

- 首次获得有效方向时只建立基准，不提醒。
- 反向候选必须在活跃目标品种报价中连续保持 10 秒。
- 候选失效、转为中性或回到原方向时，累计确认时间清零。
- 无新报价的时间不计入 10 秒。
- 同一方向确认后只提醒一次，下一次必须完成反向转换才可再次提醒。
- 报价中断超过默认 60 秒后恢复时，静默重建方向基准，不补发历史提醒。

所有技术参数均作为 EA 输入开放，并沿用现有指标的安全上限。

## 提醒行为

每次确认多转空或空转多时，按顺序执行：

1. 播放对应 MT5 声音。
2. 显示 MT5 Alert 弹窗。
3. 向 PushPlus 发送一条 App 渠道消息。

声音、弹窗和 PushPlus 各自提供独立开关。某一种提醒失败不阻断其他提醒，也不影响后续行情监控。

PushPlus 请求失败不会导致同一已确认转换被重复发送。下一次反向转换仍可正常尝试推送。

## PushPlus 接口

默认配置：

- API 地址：`https://www.pushplus.plus/send`
- 请求方法：HTTPS POST
- 内容类型：`application/json; charset=utf-8`
- 渠道：`app`
- 模板：`txt`
- 请求超时：5000 毫秒

EA 输入参数：

- 启用 PushPlus：默认是
- PushPlus Token：默认空
- API 地址
- 渠道
- 模板
- 请求超时
- 启动测试消息：默认关闭

请求 JSON 包含：

- `token`
- `title`
- `content`
- `template`
- `channel`

字符串在生成 JSON 前必须正确转义反斜杠、双引号、换行、回车和制表符。发送内容使用 UTF-8。

## 消息内容

标题根据方向生成：

- `XAUUSD M5 空转多提醒`
- `XAUUSD M5 多转空提醒`

正文包含：

```text
品种：实际监控品种
周期：M5
方向：空转多 / 多转空
服务器时间：YYYY-MM-DD HH:MM:SS
EMA：多 / 空 / 中性
Supertrend：多 / 空 / 中性
RSI：多 / 空 / 中性
确认时间：10 秒
```

启动测试消息使用标题 `XAUUSD M5 PushPlus 测试`，正文只说明 EA 已连接，不伪造交易方向。

## 启动测试消息

`InpSendStartupTest` 默认为关闭。

若用户开启：

- 仅在该次 EA 成功初始化运行时尝试发送一次。
- Token 为空时不发送，显示配置错误。
- 重新加载 EA 或修改参数属于新实例，可再次发送一次。
- 测试消息不改变多空基准或反转状态。

## 网络响应与错误处理

EA 将 HTTP 200 与 PushPlus JSON 业务响应分别校验。

成功条件：

- `WebRequest()` 返回 HTTP 200；
- 响应 JSON 中的业务 `code` 表示接收成功。

PushPlus 采用异步发送；成功只表示服务端接收请求，不保证 PushPlus App 最终送达。

错误类别：

- Token 为空；
- WebRequest 白名单未配置；
- 网络请求返回 `-1`；
- 非 HTTP 200；
- 响应缺失或业务代码不成功；
- 响应无法解析。

面板和 Experts 日志只显示错误类型、HTTP 状态、MT5 错误码或 PushPlus 业务码，不输出 Token、完整请求体或带 Token 的 URL。

Token 只存在于 EA 输入参数，不写入源码、README、测试、构建日志、Git 提交或消息面板。

- 已确认方向；

多实例使用唯一对象名前缀，卸载时只删除本实例对象。

## 初始化与重试

- 找不到目标品种或指标句柄创建失败时，EA 保持加载并在定时器中重试。
- 数据不足时不产生方向或提醒。
- 网络请求失败不自动高频重试，以避免同一转换重复消息。
- 修改 Token、URL 或白名单后，用户重新加载 EA 使配置生效。
- 卸载时释放句柄、定时器和图表对象。

## MT5 安装要求

1. 将 `XAUUSD_M5_Reversal_Alert_EA.ex5` 放入数据目录的 `MQL5\Experts`。
2. 在“工具 → 选项 → 智能交易系统”中允许 WebRequest。
3. 将 `https://www.pushplus.plus` 加入允许的 URL。
4. 将 EA 加载到任意图表。
5. 在参数中填写 PushPlus Token。
6. 开启“算法交易”，以允许 EA 运行。
7. 手机安装 PushPlus App，登录 Token 所属的同一账号，并允许系统通知和通知声音。

开启算法交易不代表本 EA 会交易；源码中不得导入交易库或调用交易 API。

PushPlus App 一个账号同时只能登录一台 App 设备；在另一台设备登录会使原设备退出。
只有 `channel=app` 的消息才直接触发 App 通知，本 EA 默认不发送 `wechat` 微信公众号渠道。

## 验证

自动验证：

- 全部 27 种投票组合；
- 首次方向静默建立基准；
- 报价恢复后静默重建基准；
- 反向不足 10 秒不提醒；
- 满 10 秒只提醒一次；
- 同方向不重复提醒；
- 消息标题和正文的多转空、空转多语义；
- Token 为空不调用网络；
- 请求及错误状态不泄露 Token；
- JSON 转义；
- 不存在交易 API；
- 参数和历史数据量有安全上限。

编译验收：

- 使用 MetaEditor 编译为 `0 errors, 0 warnings`；
- 生成 `XAUUSD_M5_Reversal_Alert_EA.ex5`；
- 记录源码和 EX5 的 SHA-256。

真实推送：

- 只有用户明确提供 Token 并授权真实外部发送后才执行；
- 默认不使用用户 Token 发测试消息；
- 最终仍需在用户 MT5 终端验证 WebRequest 白名单、PushPlus App 登录、系统通知权限、通知声音和手机最终送达。
