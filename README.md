# XAUUSD M5 自适应反转提醒 EA

`XAUUSD_M5_Reversal_Alert_EA` 是 MetaTrader 5 的监控与提醒工具。它固定读取目标黄金品种的 M5 实时报价，在电脑图表上显示连续评分、候选方向和确认进度，并在多空方向最终确认反转时播放声音、显示大号通知框，并可选发送 PushPlus App 通知。

本 EA 只监控和提醒，不下单、不平仓、不改仓，也不包含任何交易 API。启用 MT5 的“算法交易”只是让 EA 的定时器和 WebRequest 可以运行，不会授权本 EA 自动交易。

## 信号模型

默认参数采用偏均衡的短线组合：

- EMA 快线/慢线为 `7 / 18`；
- Supertrend 使用 ATR 周期 `8`、倍数 `2.4`；
- RSI 周期为 `9`，`48–52` 为中性区间。

EA 不再采用简单多数投票，而是把 EMA 距离与斜率、Supertrend 距离、RSI 动能转换为连续评分。EMA、Supertrend、RSI 的贡献相加得到 `-100.0` 到 `+100.0` 的综合评分：正值偏多，负值偏空。

方向状态使用 `55 / 35` 双阈值滞回：

- 综合评分达到 `+55` 或 `-55` 才能建立反向候选；
- 候选建立后，评分只要仍在对应方向的 `35` 维护阈值一侧，就不会因轻微波动立即失效；
- 回到中性区会消耗确认进度，明确转向相反一侧会取消候选。

确认时间根据评分强度在 `3–10` 秒之间自适应。评分越强，目标确认时间越接近 3 秒；评分刚越过候选阈值时，目标时间更接近 10 秒。只有活跃的新报价计入进度，断线或长时间无新报价不会被补算。

首次获得有效方向时只建立基准，不发送反转通知。同方向延续也不会重复提醒。

## 电脑与手机通知边界

候选方向、目标确认时间、确认进度和剩余秒数只显示在电脑端图表面板，不发送到手机。

PushPlus App 只接收最终确认的“空转多”或“多转空”反转。最终消息包含：

- 品种、M5 周期、方向和服务器时间；
- 最终综合评分；
- EMA、Supertrend、RSI 的各自贡献；
- 本次自适应确认目标时间。

启动连接测试是可选的非方向性消息，默认关闭。候选变化不会调用 PushPlus，也不会产生手机方向提醒。

电脑提示音、PushPlus 推送和图表中央的大号通知框相互独立。某一路失败不会阻断其他提醒或后续行情监控。大号通知框默认显示 15 秒，可点击右上角 `×` 关闭，并会在图表尺寸变化后重新居中。MT5 原生 `Alert` 小弹窗默认关闭，可通过参数单独开启。

## 图表面板

面板显示：

- 已确认方向；
- 以维护阈值解释的评分方向：偏多、偏空或中性；
- 带正负号和一位小数的综合评分；
- 带正负号和一位小数的 EMA、Supertrend、RSI 贡献；
- 候选方向、目标确认秒数、确认进度和非负剩余秒数；
- PushPlus 状态、运行状态以及独立的声音/推送警告。

没有候选时明确显示“候选方向：无”，确认进度和剩余时间归零。

## 安装与 PushPlus 设置

1. 在 MT5 选择“文件 → 打开数据文件夹”。
2. 将 `MQL5\Experts\XAUUSD_M5_Reversal_Alert_EA.ex5` 复制到数据目录的 `MQL5\Experts`。
3. 在“工具 → 选项 → 智能交易系统”中允许 WebRequest，并加入：
   `https://www.pushplus.plus`
4. 回到“导航器 → 智能交易系统”，右键刷新，然后把 EA 加载到任意图表。EA 始终监控目标黄金品种的 M5 数据，不受当前图表周期影响。
5. 在 EA 输入参数 `InpPushPlusToken` 中填写自己的 Token，保持 `InpEnablePushPlus=true`、`InpPushPlusChannel=app`。
6. 在手机安装并登录同一 PushPlus 账号，允许系统通知和声音。

Token 默认是空字符串，只允许在 MT5 运行参数中输入。源码、README、日志、图表面板和 Git 中都不应出现真实 Token。

### 替换或重新加载 EX5，同时保留 Token

升级 EX5 前，先在 EA“输入”页点击“保存”，把当前参数保存为本机 `.set` 文件；该文件包含 Token 时属于敏感本地文件，不要复制到项目目录或提交 Git。

然后：

1. 从图表移除旧 EA，或关闭使用它的图表；
2. 用新版同名 EX5 覆盖 MT5 数据目录 `MQL5\Experts` 中的旧文件；
3. 在导航器中右键“智能交易系统”并刷新；
4. 重新加载 EA，在“输入”页加载刚保存的本机 `.set` 文件，或手动重新输入 Token；
5. 确认面板只显示 PushPlus 状态，不显示 Token 本身。

若直接在 MetaEditor 中重新编译同名 EA，MT5 通常会重新初始化实例并保留当前输入值；仍建议先保存本机 `.set` 作为回退。EX5 本身不保存运行时 Token。

## 主要默认参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 目标品种 | `XAUUSD` | 支持经纪商前后缀自动匹配 |
| 快速 / 慢速 EMA | `7 / 18` | EMA 距离与斜率 |
| ATR 周期 / Supertrend 倍数 | `8 / 2.4` | 趋势距离 |
| RSI 周期 / 中性区 | `9 / 48–52` | 动能贡献 |
| 候选 / 维护阈值 | `55 / 35` | 双阈值滞回 |
| 最短 / 最长确认 | `3 / 10 秒` | 随评分强度自适应 |
| 最大活跃报价间隔 | `1000 毫秒` | 更长间隔不计入确认 |
| 重连重置时间 | `60 秒` | 超过后静默重建基准 |
| 定时器间隔 | `100 毫秒` | 轮询目标品种新报价 |
| 大号通知显示时间 | `15 秒` | 可点击关闭 |
| PushPlus 渠道 | `app` | 仅 PushPlus App |

周期参数的允许范围为 1–500；Supertrend 历史递推最多使用 5000 根 M5 K 线，以限制异常参数造成的资源压力。

## 验证建议

先在模拟账户或风险可控的环境中运行：

1. 核对面板显示的实际黄金品种、M5 和各项连续评分；
2. 观察 55 分建立候选、35 分维护方向以及 3–10 秒自适应目标；
3. 确认候选和进度只在电脑面板变化，手机没有候选通知；
4. 等待一次最终反转，核对声音、大号通知和 PushPlus 各自独立；
5. 确认最终消息中的综合评分等于三项贡献之和；
6. 模拟无报价或重连，确认静默时间不被计入进度且不会补发旧信号。

历史回放与旧版本比较只能说明给定样本中的行为差异，不能证明未来表现，也不构成收益承诺、投资建议或盈利保证。

## 故障排查

- `Token 未配置`：在 EA 输入参数中填写 Token 后重新加载。
- WebRequest 失败或 MT5 错误 4014：确认 EA 位于 `MQL5\Experts`，并将 `https://www.pushplus.plus` 加入允许列表。
- HTTP 或业务码错误：检查网络、代理、PushPlus 服务状态、Token 与账号绑定。
- 显示“服务端已接收”：只表示 PushPlus 接口接收请求；仍需检查手机登录、系统通知和声音权限。
- 没有提示音：检查 MT5 声音设置，以及 `alert.wav`、`timeout.wav` 是否在终端 `Sounds` 目录。

PushPlus 失败不会阻断行情监控，也不会自动重试同一条已确认反转，以避免重复消息。
